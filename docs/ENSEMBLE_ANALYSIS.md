# Ensemble analysis — every ensemble, n=3 to n=6

Requested 21 Aug. All numbers are cross-fitted (2-fold over questions, seed 0); weights, logistic coefficients, the pattern lookup, the gold-count regression and the keep threshold are fitted on the training half only. Generated by `analysis/make_ensemble_doc.py` from cached results — no recomputation.

**Two baselines.** `count` = MA-count: keep a claim if ≥θ *agents* assert it, exact string match, one vote per agent, θ cross-fitted on F1. This is the team's proposed naive multi-agent method, not a published one. `ASC` = the published pipeline (arXiv:2405.13131): edit-distance clustering at a tuned τ, strength = count of cluster *members* (not deduplicated per agent), θ tuned on a validation half to maximise F1-5, representative = first member. The two differ on three axes — exact match vs edit-distance clustering, per-agent dedup vs raw member counts, and F1 vs F1-5 as the tuning objective — so ASC is a separate arm, not a relabelling of counting.

ASC's one unavoidable substitution: published ASC draws m≈50 stochastic samples from ONE model; the cache holds one response per agent, so the m samples are replaced by the n agents (this is exactly the extension the team proposes). The LLM composition step is omitted — it costs API calls and applies equally to every arm. τ tuned to **0.05**, full-pool ASC = **28.60** F1 / 32.40 F1-5.

**Fairness check on ASC.** ASC tunes θ on **F1-5** (the paper's own objective) while every arm here is compared on **F1**, which could handicap it. Re-tuning ASC's θ on F1 instead moves it from 23.96 to 24.09 averaged over all 210 ensembles — i.e. essentially not at all (identical at n=4,5,6; +0.5 at n=3). So ASC trailing counting on F1 is a real property of the method, not an artefact of the tuning objective. ASC's F1-5 is 28.40 and is reported in the JSON.

**Other arms.** `best single` = strongest agent in that ensemble. `weighted` = marginal reliability weighting. `pattern` = shrunk `P(correct | exact subset asserting)`, which upper-bounds every rule that reads only who asserted. `rank+budget` = our method.
